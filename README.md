# Project 4 - The Serverless Logic

## Objective

Create a serverless Cost Calculator using AWS Lambda.

## Technology Used

- AWS Lambda
- Python
- GitHub
- VS Code

## Functionality

The Lambda function accepts two numbers and returns their sum.

## Example Input

{
    "num1": 7,
    "num2": 3
}

## Example Output

{
    "sum": 10
}
